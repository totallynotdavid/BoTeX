# Manual

Read these documents in order when operating or changing botkit:

1. [Offline REPL](repl.md) runs a bot in the terminal without a WhatsApp
   account.
2. [Pairing](pairing.md) links a bot to a WhatsApp account.
3. [Running](running.md) covers starting, stopping, logs, the systemd unit, and
   exit statuses.
4. [Configuration](configuration.md) lists every environment variable and its
   default.
5. [The latex bot](latex-bot.md) covers access, commands, rendering, and limits.
6. [The flow bot](flow-bot.md) covers writing a flow and the JSON format.
7. [Architecture](architecture.md) maps the code and its boundaries.

To change botkit, read [contributing](../.github/contributing.md).
