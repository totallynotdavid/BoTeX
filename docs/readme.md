# Manual

Read these documents in order when operating or changing botkit:

1. [Operations](operations.md) covers installation, pairing, running, logs,
   shutdown, and exit statuses.
2. [Configuration](configuration.md) lists every environment variable and its
   default.
3. [The LaTeX bot](latex.md) covers access, commands, rendering, and limits.
4. [The flow bot](flow.md) covers conversations and the JSON flow format.
5. [Development](development.md) covers the local checks and test boundaries.

The package map is in [ARCHITECTURE.md](../ARCHITECTURE.md).
